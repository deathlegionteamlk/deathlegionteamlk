## <img src="https://api.iconify.design/mdi/skull-outline.svg?color=%23ff0033" width="24"/> Who we are

```bash
┌──(legion㉿lk)-[~]
└─$ cat about.md
```

> We're a small Sri Lankan dev group, not a company. There's no funding round behind any of this, just people who wanted certain tools to exist and got tired of waiting. Full-stack apps, OS/kernel-level tooling, AI agents, CLI utilities — whatever we're stuck on that week. If it's on this org, it's MIT-licensed. If it's still rough, the README will say so instead of pretending otherwise.
>
> Stars are nice but they're not the point. We build the thing we personally wanted, ship it, and move on to whatever's next.
