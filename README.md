Death Legion Team is a small dev group out of Sri Lanka. Full-stack apps, OS and kernel-level tooling, AI agents, CLI tools — whatever we're stuck on that week ends up as a repo here. No investor deck behind any of it. We build the thing we personally wanted to exist, ship it, and move on. If something's still rough, the repo's README says so instead of dressing it up.

### How we work

We don't call a fork original work — if dazki's original, that's because it actually is, and if something ever isn't, we'll say so up front. Everything on this org is MIT, no exceptions, no "contact us for a commercial license" fine print. Documentation gets written to be read, not to cover us legally. And if a project's half-finished, the README says half-finished — we'd rather you know what you're installing than read a good pitch for it.
