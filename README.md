## 🚀 About Us

We are a **Sri Lankan cyber team** building next-gen developer tools, AI agents, OS kernels, and CLI utilities. We ship fast, ship free, and ship for everyone.

- 🌍 **Location:** Sri Lanka 🇱🇰
- 🛠️ **Focus:** Full-Stack Dev | OS Kernels | AI Agents | CLI Tools
- 🆓 **Philosophy:** Everything we build is free and open
- 🤖 **AI:** Claude, Ollama, custom agents
- ⚡ **Stack:** TypeScript, Rust, Go, Python, C
