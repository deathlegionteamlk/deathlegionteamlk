## <img src="https://api.iconify.design/mdi/account-group.svg?color=%236e7681" width="24"/> Who We Are

Sri Lanka's premier cyber team. We build developer tools, AI agents, OS kernels, and CLI utilities. Everything we make is free and open source.

- 🌍 **Location:** Sri Lanka 🇱🇰
- 🛠️ **Focus:** Full-Stack Development | OS Kernels | AI Agents | CLI Tools
- 🆓 **Philosophy:** Free and open source, always
- 🤖 **AI:** Claude, Ollama, custom agents
- ⚡ **Stack:** TypeScript, Rust, Go, Python, C, Assembly
