## <img src="https://img.icons8.com/fluency/32/info.png" width="24"/> About Death Legion Team

<img src="https://media.giphy.com/media/ZVik7pBtu9dNS/giphy.gif" width="300" align="right" alt="Death Legion Team DEMO X HEXA"/>

**Death Legion Team** (also known as **deathlegionteamlk** on GitHub) is an open source development group based in **Sri Lanka**, operating under the banner **DEMO × HEXA**.

We've shipped apps with pretty much every popular framework, hit the same walls every time, and eventually stopped complaining and started building. That's the honest origin of everything here.

Three projects so far. An AI multi-agent system called **LEGIONGASPER** that coordinates parallel agents using a captain-agent pattern. A local CLI agent framework called **LEGIONHERCULES** that runs entirely on your own hardware via Ollama — no API keys, no cloud, no billing. And **legionnative**, a cross-platform mobile framework in TypeScript with a Rust core, built because we were tired of 3-second cold starts and bundles that bloated with every dependency.

All three are MIT licensed. All three are built in public. All three exist because we needed them.

### <img src="https://img.icons8.com/fluency/28/robot.png" width="22"/> [LEGIONGASPER](https://github.com/deathlegionteamlk/LEGIONGASPER) — Multi-Agent AI System

<img src="https://media.giphy.com/media/3oKIPnAiaMCws8nOsE/giphy.gif" width="280" align="right" alt="LEGIONGASPER multi-agent AI system Death Legion Team Python FastAPI"/>

[![Python](https://img.shields.io/badge/Python-88.7%25-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://github.com/deathlegionteamlk/LEGIONGASPER)
[![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=for-the-badge&logo=fastapi&logoColor=white)](https://github.com/deathlegionteamlk/LEGIONGASPER)
[![HTML](https://img.shields.io/badge/HTML+CSS-Dashboard-E34F26?style=for-the-badge&logo=html5&logoColor=white)](https://github.com/deathlegionteamlk/LEGIONGASPER)
[![MIT License](https://img.shields.io/badge/License-MIT-FF2D20?style=for-the-badge)](https://github.com/deathlegionteamlk/LEGIONGASPER)

**LEGIONGASPER** is a Python multi-agent AI system built by Death Legion Team. You give it a task. A captain agent breaks it into subtasks, forms a squad of specialized agents, runs them in parallel, and merges the results. You don't wire the handoffs. You don't babysit the coordination.

It runs on FastAPI, exposes a REST + WebSocket API on port 8081, and ships with a live dashboard at `localhost:8080` showing active agents, task queue, completion rates, and cost per provider — all live, no polling.

Memory works across five layers so nothing gets forgotten at the wrong time: Session (current run) → Working (current task focus) → Daily (survives the session) → Long-term (ChromaDB vector store, survives reboots) → Collective (shared across all agents).

```python
# LEGIONGASPER — Captain-Agent pattern example
captain = Captain(agent_id="research_lead")

subtasks = captain.decompose_task("Analyze market trends in AI tooling")
squad    = captain.form_squad(subtasks)
results  = await squad.execute_parallel()
final    = captain.aggregate_results(results)
```

### <img src="https://img.icons8.com/fluency/28/console.png" width="22"/> [LEGIONHERCULES](https://github.com/deathlegionteamlk/LEGIONHERCULES) — Local CLI Agent Framework

<img src="https://media.giphy.com/media/dWesBcTLavkZuG35MI/giphy.gif" width="280" align="right" alt="LEGIONHERCULES local CLI agents Ollama Death Legion Team"/>

[![Ollama](https://img.shields.io/badge/Ollama-Local%20LLM-F97316?style=for-the-badge)](https://github.com/deathlegionteamlk/LEGIONHERCULES)
[![Docs](https://img.shields.io/badge/Docs-legionhercule.pages.dev-6366F1?style=for-the-badge&logo=cloudflare&logoColor=white)](https://legionhercule.pages.dev)
[![MIT](https://img.shields.io/badge/License-MIT-A855F7?style=for-the-badge)](https://github.com/deathlegionteamlk/LEGIONHERCULES)

**LEGIONHERCULES** is a CLI framework by Death Legion Team for autonomous AI agents that run 100% locally via Ollama. No API key. No cloud server. No billing page. Pull a model once, run agents on your own hardware for free.

The agents aren't chatbots with a tool call bolted on. They plan multi-step tasks, pick tools, execute them, read results, and keep looping until done. Multiple agents can run in parallel. The terminal UI is Rich. CLI is Typer.

### <img src="https://img.icons8.com/fluency/28/iphone.png" width="22"/> [legionnative](https://github.com/deathlegionteamlk/legionnative) — Cross-Platform Mobile Framework

<img src="https://media.giphy.com/media/l3q2K5jinAlChoCLS/giphy.gif" width="280" align="right" alt="legionnative cross-platform mobile framework TypeScript Death Legion Team"/>

[![TypeScript](https://img.shields.io/badge/TypeScript-93.9%25-3178C6?style=for-the-badge&logo=typescript&logoColor=white)](https://github.com/deathlegionteamlk/legionnative)
[![Rust](https://img.shields.io/badge/Rust-Core-000000?style=for-the-badge&logo=rust&logoColor=white)](https://github.com/deathlegionteamlk/legionnative)
[![Platforms](https://img.shields.io/badge/Android%20%7C%20iOS%20%7C%20Web-22C55E?style=for-the-badge)](https://github.com/deathlegionteamlk/legionnative)
[![MIT](https://img.shields.io/badge/License-MIT-00D9A3?style=for-the-badge)](https://github.com/deathlegionteamlk/legionnative)

**legionnative** is a cross-platform mobile framework by Death Legion Team. It was born from shipping apps with Expo, React Native, and Flutter and hitting the same problems every time: 3-second cold starts, hot reload that lied about being instant, bundles that grew by 400KB when you added one dependency, and "offline-first" that really meant "cache one screen."

TypeScript runtime. Rust core for what JS is slow at. Vite for dev. Skia for consistent rendering across devices. WASM plugin system for native code in any language.
