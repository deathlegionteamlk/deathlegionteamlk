## <img src="https://img.icons8.com/fluency/32/info.png" width="24"/> Who We Are

<img src="https://media.giphy.com/media/ZVik7pBtu9dNS/giphy.gif" width="300" align="right" alt="team gif"/>

We're DEMO × HEXA and the Death Legion Team. We've shipped apps with pretty much every popular framework, got annoyed by the same problems repeatedly, and eventually decided to just fix them ourselves.

That's not a mission statement. That's just what happened.

Three projects so far: an AI agent system that runs on your own hardware, a CLI framework for autonomous agents, and a cross-platform mobile framework that actually starts fast. All open source, all MIT, all built because we needed them.

We're based in Sri Lanka and we write things in Python and TypeScript, mostly. Rust shows up in the mobile framework's core where JavaScript is too slow.

### <img src="https://img.icons8.com/fluency/28/robot.png" width="22"/> [LEGIONGASPER](https://github.com/deathlegionteamlk/LEGIONGASPER)

<img src="https://media.giphy.com/media/3oKIPnAiaMCws8nOsE/giphy.gif" width="280" align="right" alt="gasper gif"/>

[![Python](https://img.shields.io/badge/Python-88.7%25-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://github.com/deathlegionteamlk/LEGIONGASPER)
[![FastAPI](https://img.shields.io/badge/FastAPI-Latest-009688?style=for-the-badge&logo=fastapi&logoColor=white)](https://github.com/deathlegionteamlk/LEGIONGASPER)
[![License](https://img.shields.io/badge/License-MIT-FF2D20?style=for-the-badge)](https://github.com/deathlegionteamlk/LEGIONGASPER)

You give it a task. It breaks the task into pieces, hands each piece to a specialized agent, runs them in parallel, and stitches results back together. The captain handles coordination — you don't.

It runs on FastAPI, has a live dashboard at `localhost:8080`, and speaks OpenAI, Anthropic, and OpenRouter without extra wiring. Memory works across five layers — from what an agent is doing right now down to a ChromaDB vector store that survives reboots.

<br clear="right"/>

<div align="center">

| <img src="https://img.icons8.com/fluency/20/artificial-intelligence.png"/> | **Captain-Agent Pattern** | One captain, many agents. You talk to the captain. |
| <img src="https://img.icons8.com/fluency/20/server.png"/> | **5-Layer Memory** | Session → Working → Daily → Long-term → Collective |
| <img src="https://img.icons8.com/fluency/20/module.png"/> | **Multi-Provider** | OpenAI, Anthropic, OpenRouter — swap per agent |
| <img src="https://img.icons8.com/fluency/20/monitor.png"/> | **Live Dashboard** | `localhost:8080` — agents, queue, cost, all live |
| <img src="https://img.icons8.com/fluency/20/shield.png"/> | **Governance** | Audit logs, cost tracking, rate limits, RBAC |
| <img src="https://img.icons8.com/fluency/20/api.png"/> | **REST + WebSocket** | Full API on port 8081 — integrate from anything |

### <img src="https://img.icons8.com/fluency/28/console.png" width="22"/> [LEGIONHERCULES](https://github.com/deathlegionteamlk/LEGIONHERCULES)

<img src="https://media.giphy.com/media/077i6AULCXc0FKTj9s/giphy.gif" width="280" align="right" alt="hercules gif"/>

[![Python](https://img.shields.io/badge/Python-3.9%2B-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://github.com/deathlegionteamlk/LEGIONHERCULES)
[![Ollama](https://img.shields.io/badge/Ollama-Local-F97316?style=for-the-badge)](https://github.com/deathlegionteamlk/LEGIONHERCULES)
[![Docs](https://img.shields.io/badge/Docs-legionhercule.pages.dev-6366F1?style=for-the-badge&logo=cloudflare&logoColor=white)](https://legionhercule.pages.dev)

CLI framework for autonomous AI agents that run locally via Ollama. No API key. No cloud. No billing page. Pull a model once, run it on your own hardware forever.

Agents plan multi-step tasks and execute them — they don't just respond to prompts. Multiple agents can run in parallel. The terminal UI is Rich. The CLI is Typer.

### <img src="https://img.icons8.com/fluency/28/iphone.png" width="22"/> [legionnative](https://github.com/deathlegionteamlk/legionnative)

<img src="https://media.giphy.com/media/l3q2K5jinAlChoCLS/giphy.gif" width="280" align="right" alt="mobile gif"/>

[![TypeScript](https://img.shields.io/badge/TypeScript-93.9%25-3178C6?style=for-the-badge&logo=typescript&logoColor=white)](https://github.com/deathlegionteamlk/legionnative)
[![Platforms](https://img.shields.io/badge/Android%20%7C%20iOS%20%7C%20Web-cross--platform-22C55E?style=for-the-badge)](https://github.com/deathlegionteamlk/legionnative)
[![License](https://img.shields.io/badge/License-MIT-00D9A3?style=for-the-badge)](https://github.com/deathlegionteamlk/legionnative)

Cross-platform mobile framework. We built this after shipping apps with every other option and hitting the same walls: 3-second cold starts, fake hot reload, bundles that grew with every dependency, "offline-first" that really meant "cache one screen."

Cold start under 100ms. Hot reload under 50ms. Base bundle under 50KB. Works on Android Go devices with 1GB RAM. Offline that's actually offline.

<br clear="right"/>

<div align="center">

| <img src="https://img.icons8.com/fluency/20/lightning-bolt.png"/> | Metric | Target | Why it matters |
|:---:|:---|:---|:---|
| <img src="https://img.icons8.com/fluency/18/launch.png"/> | Cold Start | **< 100ms** | Users don't wait. They leave. |
| <img src="https://img.icons8.com/fluency/18/refresh.png"/> | Hot Reload | **< 50ms** | You ship faster |
| <img src="https://img.icons8.com/fluency/18/box.png"/> | Base Bundle | **< 50KB** | Downloads matter on 3G |
| <img src="https://img.icons8.com/fluency/18/memory-slot.png"/> | Memory | **< 20MB** | Budget devices work |
| <img src="https://img.icons8.com/fluency/18/wifi-off.png"/> | Offline | **Full** | No connection? No problem |

</div>
