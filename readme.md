## <img src="https://cdn.simpleicons.org/aboutdotme/FF6B6B" width="26"/> Who we are

We're a small crew out of Sri Lanka building whatever we're curious about that week — OS kernels, LLM agents, a homemade programming language, an emulator, a browser, and a Firebase clone, among other things. No roadmap, no product-market fit, just repos.

Most of this is unlicensed or MIT'd and half-documented. If something looks unfinished, it probably is. We fix it when we get back to it.
